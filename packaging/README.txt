SCRIPTURESYNC INSTALLATION

1. Extract the entire ZIP file before installing.
2. Close ScriptureSync if it is currently running.
3. Double-click "Install ScriptureSync.cmd".
4. Restart OpenLP if the installer adds or updates the plugin.
5. On the first installation, activate ScriptureSync under
   Settings > Manage Plugins in OpenLP.

The package includes the required .NET runtime. Administrator access, Git, and
the .NET SDK are not required.
